# Title

Voices of Embervale — Russian AI journal voice-over (beta)

# Short description

520 Russian audio segments for Enshrouded journal entries. Press F3 in game to toggle the Russian voice-over independently of the selected voice language. Original languages remain available.

# Description

This early beta covers 520 journal audio segments, not every letter or NPC dialogue. The recordings were synthesized with Silero TTS. Feedback on pronunciation, delivery, mismatched text, silence, and technical issues is welcome.

Press F3 in game to enable Russian audio for covered entries. A small indicator appears near the top-right edge. Press F3 again to return to the voice language selected in the game. You can launch Enshrouded normally; no special command line is needed.

## Compatibility

- Windows x64; tested Enshrouded 1.0 build with `enshrouded.exe` SHA-256 `82e5020a8736348cd0374f004b2f5e5ef456b5bd27aa5420df34c7dd241cfeeb`.
- Other builds are rejected before file changes. Please wait for an updated mod after a game update.
- Mods that change `enshrouded.kfc`, `enshrouded.kfc_resources`, `dbghelp.dll`, `winmm.dll`, or `shroudtopia.dll` may conflict. The installer will not overwrite unknown DLLs.

## Install

1. Download and **fully extract** the main ZIP. Do not run the EXE from inside the archive.
2. Close Enshrouded and start `VoiceInstaller.exe` from the extracted folder.
3. Select the **game directory containing** `enshrouded.exe` — select the folder, not the EXE itself.
4. Click “Проверить состояние” (Check status), then “Установить мод” (Install mod), and wait for completion.
5. Start the game normally. Press F3 and test a covered journal entry.

Keep the extracted folder for reinstalling. The installer works offline and does not download or transmit data.

## Disable or uninstall

Close the game first. “Отключить · копию сохранить” (Disable, keep backup) restores the original game indexes and removes the mod while retaining the backup. “Удалить мод и копию” (Remove mod and backup) also removes the installer's backup. If another mod or a game update changed the same files, automatic removal stops for safety.

## Known limitations

- Partial journal coverage; NPCs are not dubbed.
- Compatibility is pinned to the tested game build.
- F3 must not be captured by another global hotkey.
- The installer is unsigned and Windows may show a standard warning. Source code and hashes are included in the archive.

For feedback, include the journal entry title, what you heard, the expected text, and your game version. For technical reports, include the installer status and any other mod loader in use.
