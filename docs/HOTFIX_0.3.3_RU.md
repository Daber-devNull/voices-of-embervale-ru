# Голоса Эмбервейла 0.3.3 beta — исправление совместимости 03.11.2026

Проверена сборка Enshrouded 1285601. Исправлена ошибка `RU separate voice: format changed`: обновление изменило длительность нескольких английских записей. Русские звуки теперь получают собственные frameCount и duration из упакованной озвучки. Проверки файлов, частоты 48000 Гц и связей ресурсов сохранены. Включены ранее одобренные 46 реплик Коллекционера; проб Кузнеца нет.

## Быстрая ручная замена уже установленного мода

1. Полностью закройте Enshrouded и установщик.
2. Сохраните папку `mods/ru_voice_separate_525` за пределами `mods`, например в отдельную папку резервных копий. Не оставляйте копию внутри `mods`: загрузчик может принять её за второй мод.
3. Из архива Hotfix скопируйте папку `mods` в папку с `enshrouded.exe`, согласитесь на замену. В архиве находятся исправленный Lua, манифесты и необходимые файлы Коллекционера. Остальные 1711 файлов уже установленной озвучки остаются на месте.
4. Запустите игру привычным способом. F3 включает/выключает озвучку. Фактическое воспроизведение после этого патча ещё требует игровой проверки; офлайн-проверки перечислены ниже.
5. Старый установщик может считать файлы изменёнными после ручной замены. Не нажимайте в нём восстановление старой копии после обновления игры. Для дальнейшего управления выполните чистую переустановку ниже.

## Ручное удаление и чистая переустановка после обновления игры

1. Закройте игру и все установщики.
2. Переместите `mods/ru_voice_separate_525` из папки игры в свою папку резервных копий ВНЕ `mods`. Это отключает именно пакет русской озвучки.
3. Переместите `.ru_voice_backup` и `enshrouded.kfc.bak` в ту же папку резервных копий. НЕ копируйте из них старые `enshrouded.kfc` / `enshrouded.kfc_resources` поверх обновлённой игры: старые индексы несовместимы с новой сборкой.
4. Если `dbghelp.dll`, `winmm.dll` и `shroudtopia.dll` используются ТОЛЬКО этой озвучкой, переместите их в резервную папку. Если загрузчик или DLL используются другими модами, оставьте их и не заменяйте вслепую. Не трогайте `dinput8.dll`, `wsock32.dll`, `steam_api64.dll` и DLL других модов.
5. Steam → Enshrouded → Свойства → Установленные файлы → Проверить целостность файлов. Это возвращает актуальные игровые индексы. Не удаляйте `enshrouded_*.dat` вручную и не удаляйте сохранения.
6. Полностью распакуйте ПОЛНЫЙ архив 0.3.3 beta в отдельную папку. Запустите новый `VoiceInstaller.exe`, выберите папку с `enshrouded.exe`, нажмите «Установить мод». Если найден конфликт общей DLL, остановитесь и сохраните журнал; не подменяйте файлы других модов.
7. Новый установщик сохраняет оставшиеся нессылаемые модовые DAT в `.ru_voice_orphan_dats`; файл переносится только после проверки таблицы текущего индекса. Не нужно удалять его вручную.
8. Запустите игру самостоятельно, включите F3 и проверьте найденную записку и разговор с NPC.

## Проверка и диагностика

Офлайн-сборка: 1118 связей озвучки, 1711 аудиоресурсов с проверкой содержимого, размеров, frameCount и duration, в том числе 110 звуковых вариантов Коллекционера. Три сигнатуры аудиофункций нового EXE найдены однозначно. Это не заменяет игровую проверку.

При проблеме приложите `ru_voice_installer.log`, `ru_voice_runtime.log` и снимок ошибки. В новом установщике управляющие ANSI-коды удаляются из текста ошибки.
