# Голоса Эмбервейла — исходный код beta 0.3.1

Исходники установщика (`installer/`), нашего runtime-мода (`runtime/`), скрипты подготовки озвучки (`scripts/`, `tools/audio/`), а также точная копия исходников Enshrouded Mod Loader v0.2.0 (`third_party/EML-0.2.0/`). В `runtime/minhook/` находится использованный MinHook v1.3.4. Сведения об авторах и лицензиях — в `THIRD_PARTY.md` и `licenses/`.

Аудио, игровые файлы, модели TTS, скомпилированные DLL и установщик в этот репозиторий не входят. Готовый пользовательский архив публикуется отдельно на Nexus Mods. Это сохраняет репозиторий небольшим и не дублирует сотни мегабайт записей в истории Git.

`installer/VoiceInstaller.csproj` собирается через .NET 8 SDK для Windows x64. Для автономного EXE используйте `dotnet publish installer/VoiceInstaller.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`. Инструкция по сборке DLL находится в `runtime/BUILDING.md`. Версия 0.3.1 содержит 525 страниц и 593 текстовые реплики персонажей: всего 1118 переключаемых записей и 1711 звуковых файлов с учётом случайных дублей. В 134 страницах с цифрами числа заново озвучены словами. Скрипты `build_npc_catalog.py`, `build_npc_variant_catalog.py` и `build_npc_multi_catalog.py` сопоставляют звуки с русскими строками игры; `generate_npc_voices.py`, `generate_npc_variants.py` и `generate_npc_multi.py` создают разные голоса персонажей. Извлечённые игровые тексты и аудио в GitHub не публикуются. Скрипт упаковки рассчитан на рабочее дерево автора с локально проверенным аудио и не сможет собрать пользовательский пакет из одних только исходников GitHub. В beta 0.3.1 исправлена кодировка надписи F3. Новые записи прошли проверку длительности и кодирования; прослушивание в игре ожидает проверки игроком.

Сборка мода привязана к конкретной версии Enshrouded и проверяет SHA-256 игры. Не обходите эту проверку при обновлении игры: адреса и формат ресурсов могут измениться.

На собственный код пока не назначена отдельная лицензия; лицензии сторонних проектов действуют независимо. Если хотите предложить исправление, откройте issue или pull request.
