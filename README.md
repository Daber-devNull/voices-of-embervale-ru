# Голоса Эмбервейла — исходный код beta 0.1.0

Исходники установщика (`installer/`), нашего runtime-мода (`runtime/`), а также точная копия исходников Enshrouded Mod Loader v0.2.0 (`third_party/EML-0.2.0/`). В `runtime/minhook/` находится использованный MinHook v1.3.4. Сведения об авторах и лицензиях — в `THIRD_PARTY.md` и `licenses/`.

Аудио, игровые файлы, модели TTS, скомпилированные DLL и установщик в этот репозиторий не входят. Готовый пользовательский архив публикуется отдельно на Nexus Mods. Это сохраняет репозиторий небольшим и не дублирует сотни мегабайт записей в истории Git.

`installer/VoiceInstaller.csproj` собирается через .NET 8 SDK для Windows x64. Для автономного EXE используйте `dotnet publish installer/VoiceInstaller.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`. Инструкция по сборке DLL находится в `runtime/BUILDING.md`. Скрипты упаковки рассчитаны на рабочее дерево автора с локально проверенным аудио и не смогут собрать пользовательский пакет из одних только исходников GitHub.

Сборка мода привязана к конкретной версии Enshrouded и проверяет SHA-256 игры. Не обходите эту проверку при обновлении игры: адреса и формат ресурсов могут измениться.

На собственный код пока не назначена отдельная лицензия; лицензии сторонних проектов действуют независимо. Если хотите предложить исправление, откройте issue или pull request.
