# Голоса Эмбервейла — исходный код beta 0.2.0

Исходники установщика (`installer/`), нашего runtime-мода (`runtime/`), скрипты подготовки озвучки (`scripts/`, `tools/audio/`), а также точная копия исходников Enshrouded Mod Loader v0.2.0 (`third_party/EML-0.2.0/`). В `runtime/minhook/` находится использованный MinHook v1.3.4. Сведения об авторах и лицензиях — в `THIRD_PARTY.md` и `licenses/`.

Аудио, игровые файлы, модели TTS, скомпилированные DLL и установщик в этот репозиторий не входят. Готовый пользовательский архив публикуется отдельно на Nexus Mods. Это сохраняет репозиторий небольшим и не дублирует сотни мегабайт записей в истории Git.

`installer/VoiceInstaller.csproj` собирается через .NET 8 SDK для Windows x64. Для автономного EXE используйте `dotnet publish installer/VoiceInstaller.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`. Инструкция по сборке DLL находится в `runtime/BUILDING.md`. Версия 0.2.0 поддерживает 525 страниц и 294 текстовые реплики 11 персонажей; всего 819 переключаемых записей и 876 звуковых файлов с учётом случайных дублей. В 134 страницах с цифрами числа заново озвучены словами. Скрипты `scripts/build_npc_catalog.py` и `scripts/build_npc_variant_catalog.py` сопоставляют звуки, ресурсы озвучки и русские строки оригинальной игры, а `scripts/generate_npc_voices.py` и `scripts/generate_npc_variants.py` создают разные голоса персонажей. Извлечённые игровые тексты и аудио в GitHub не публикуются. Скрипт упаковки рассчитан на рабочее дерево автора с локально проверенным аудио и не сможет собрать пользовательский пакет из одних только исходников GitHub. Новые записи прошли проверку длительности, кодирования и установки; прослушивание в игре ожидает проверки игроком.

Сборка мода привязана к конкретной версии Enshrouded и проверяет SHA-256 игры. Не обходите эту проверку при обновлении игры: адреса и формат ресурсов могут измениться.

На собственный код пока не назначена отдельная лицензия; лицензии сторонних проектов действуют независимо. Если хотите предложить исправление, откройте issue или pull request.
